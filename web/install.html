Install

Three commands and a terminal restart — that’s the whole ceremony.

Clone the repo

Anywhere you like — the installer copies what it needs to ~/.local/bin.

git clone https://github.com/runvoid/u-install.git
cd u-install

Run the installer

It copies the 18 commands, sets up shell completions (bash/zsh) and configures your PATH.

chmod +x ./install
./install

Restart your terminal

Or source ~/.bashrc / ~/.zshrc. Verify:

$ u-install --version
u-install 1.4.1
$ u-doctor --fix   # optional setup wizard

#Requirements

bash, curl and git. Nix is optional (u-install can bootstrap it on demand with --nix), AUR support needs base-devel on Arch-based systems.

#Updating & removing

Self-update

Checksum-verified updates from GitHub Releases:

u-install --self-update
# or everything at once:
u-update --self

Uninstall

Removes binaries, data, config — and the lines it added to your shell rc files:

./install --uninstall
Fresh machine? Run u-doctor --fix after installing — the wizard creates your config, checks PATH and offers a starter @dev-tools profile.

The .u format

A .u file is a plain-text snapshot of your whole u-install setup: installer configuration plus every tracked package with its source and pinned version. Diff it, git it, edit it by hand — or feed it to u-import on a new machine.

#Anatomy

# u-install export
# format: u3

[meta]
version=1.4.1
exported=2026-08-16
hostname=my-pc
sha256=fe617d48…

[config]
prefer_source = auto
auto_update_check = true

[packages]
firefox|native|141.0-1
neovim|nix|0.10.4
brave-bin|aur|1.79.118

[meta]

Who created the file and when. The sha256 line is the integrity checksum — it covers both [config] and [packages], so tampering with either is detected on import.

[config]

Key-value pairs copied from u-install.conf. u-import asks before applying them.

[packages]

One package per line: name|source|version. The pinned version is honored best-effort on import (apt and dnf pin exactly; use u-import --latest to ignore pins).

#Format history

u1

name|source — the original line-based snapshot. Still accepted everywhere.

u2

+ versions & signatures — pinned versions per package and a sha256 over [packages].

u3

current — the signature now covers [config] too. Legacy u2 files import with a warning and an explicit confirmation.

#Workflow

# Machine A — snapshot everything:
u-export setup.u

# Copy setup.u to Machine B, then:
u-import setup.u                   # config + all packages
u-import --packages-only setup.u   # skip config
u-import --latest setup.u          # ignore version pins

# Or converge an existing machine (interactive review screen):
u-sync setup.u

# Compare two snapshots:
u-diff laptop.u desktop.u
Integrity: u-import and u-sync verify the embedded sha256 and refuse tampered files unless you explicitly confirm.

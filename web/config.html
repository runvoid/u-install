Configuration

One INI-ish file: ~/.config/u-install/u-install.conf. Create and tune it interactively with u-doctor --fix, or copy the example below.

#Options

KeyDefaultDescription
prefer_sourceautoWhich source to try first: auto, native, nix or aur. auto probes native → Nix → AUR.
auto_yesfalseAssume yes for every prompt (same as passing -y). Critical-package confirmations still require an explicit yes.
aur_build_dir~/.local/share/u-install/aurWhere AUR packages are cloned and built. ~ is expanded.
aur_security_checktrueScan PKGBUILDs for dangerous patterns before building; show warnings and ask before continuing.
cleanup_after_buildfalseDelete the AUR clone after a successful build (re-clonable anytime).
nix_channelnixpkgsNix channel used for u-install --nix.
colorstrueColored output on terminals (automatically off when piped).
log_levelinfodebug, info or warn.
auto_update_checktrueQuietly check GitHub Releases for a newer u-install at most once per interval.
update_check_interval_days7How often the background update check may hit the network.

#Full example

[options]
aur_build_dir = ~/.local/share/u-install/aur
auto_yes = false
prefer_source = auto
colors = true
log_level = info
cleanup_after_build = false
nix_channel = nixpkgs
aur_security_check = true
auto_update_check = true
update_check_interval_days = 7
Unknown keys are ignored, # starts a comment, and values never need quotes. Your config is exported inside the [config] section of every .u snapshot.

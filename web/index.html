#Why u-install?

Universal

Arch, Debian, Fedora, Alpine, Void, Gentoo, NixOS, Termux and more — one interface for all of them.

Auto-detect

Type u-install firefox — it finds the best source, remembers your choice, and gets out of the way.

Portable setup

u-export your whole environment into one signed .u file, u-import it on any machine.

AUR safety

u-peek inspects metadata and scans PKGBUILDs for red flags before anything gets built.

Polished TUI

Progress bars with percentages, colored status tables, checkbox review screens — all in a terminal.

Featherweight

Pure Bash, ~100 KB total, installs in three seconds. No Python, no Node, no daemons.

#Quick install

$ git clone https://github.com/runvoid/u-install.git
$ cd u-install && chmod +x ./install
$ ./install
[install] Installation complete. # restart your terminal

Requires only bash, curl and git. Then start with the install guide or run u-doctor --fix for the setup wizard.
